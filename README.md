# 模型人格切换

> 一键切换模型、人格、TTS、STT、识图模型的 AstrBot 插件

## ✨ 功能

| 分类 | 指令 | 说明 |
|------|------|------|
| 🔹 帮助 | `#帮助` | 查看所有可用指令及说明 |
| 🔹 模型 | `#模型列表` | 列出所有已配置的聊天模型，当前模型标记 🔵 |
|         | `#模型 <序号>` | 切换当前会话使用的聊天模型 |
|         | `#当前` | 查看当前会话正在使用的聊天模型 |
| 🔹 人格 | `#人格列表` | 列出所有已配置的人格，当前人格标记 🔵 |
|         | `#人格 <序号>` | 切换当前会话使用的人格 |
|         | `#当前人格` | 查看当前会话正在使用的人格 |
| 🔹 TTS  | `#TTS列表` | 列出所有已配置的 TTS 语音合成引擎 |
|         | `#TTS <序号>` | 切换当前会话使用的 TTS 引擎 |
|         | `#当前TTS` | 查看当前会话正在使用的 TTS 引擎 |
| 🔹 STT  | `#STT列表` | 列出所有已配置的 STT 语音识别引擎 |
|         | `#STT <序号>` | 切换当前会话使用的 STT 引擎 |
|         | `#当前STT` | 查看当前会话正在使用的 STT 引擎 |
| 🔹 识图 | `#识图列表` | 列出可用的识图模型（优先显示支持多模态的模型） |
|         | `#识图 <序号>` | 切换当前会话使用的识图模型 |
|         | `#当前识图` | 查看当前会话正在使用的识图模型 |

## 🚀 安装

### 方式一：插件市场安装

1. 进入 AstrBot 管理面板
2. 搜索 `模型人格切换` 或插件名
3. 点击安装

### 方式二：Git 克隆安装

```bash
cd AstrBot的插件目录
git clone https://github.com/Ling2408/astrbot_plugin_quick_switch.git
```

### 方式三：直接下载

1. 点击右上角 `Code` → `Download ZIP`
2. 解压到 AstrBot 的 `data/plugins/` 目录

## 🔧 配置

无需额外配置，插件自动读取 AstrBot 已配置的：

- 聊天模型提供商
- 人格列表
- TTS 引擎
- STT 引擎
- 识图模型（优先筛选支持多模态图片输入的模型）

## 💡 说明

- 所有指令仅限**管理员**使用
- 切换操作仅影响**当前会话**，不影响其他会话
- 人格切换通过 `session_service_config` 实现，优先级高于全局默认人格
- 识图模型会优先筛选支持 `image` 多模态输入的提供商
