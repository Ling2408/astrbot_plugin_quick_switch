# 🔀 模型人格切换 (astrbot_plugin_quick_switch)

多模型 & 人格一键切换，无需进入后台配置，聊天窗口内直接操作。

> 版本：v2.5  
> 作者：suzune  
> 仅限管理员使用

---

## ✨ 功能

- 📋 快速查看已配置的模型列表，用颜色标记当前生效模型
- 🔄 一键切换当前会话使用的模型
- 🎭 快速查看已配置的人格列表，用颜色标记当前生效人格
- 🔄 一键切换当前会话使用的人格
- 📖 内置帮助指令，随时查看所有命令

---

## 📦 安装

将 `astrbot_plugin_quick_switch` 文件夹放入 AstrBot 的 `data/plugins/` 目录下，重启或等待热加载即可。

> 📌 本插件包含 `metadata.yaml` 元数据文件和 `logo.png` 图标，确保完整放入。

---

## 🎯 指令一览

| 指令 | 说明 |
|------|------|
| `#帮助` | 查看所有可用指令 |
| `#模型列表` | 列出所有已配置的模型，当前模型标记 🔵 |
| `#模型 <序号>` | 切换到指定序号的模型 |
| `#当前` | 查看当前会话正在使用的模型 |
| `#人格列表` | 列出所有已配置的人格，当前人格标记 🔵 |
| `#人格 <序号>` | 切换到指定序号的人格 |
| `#当前人格` | 查看当前会话正在使用的人格 |

---

## 🚀 使用示例

### 查看帮助

```
#帮助
```

输出：

```
📖 模型人格切换 v2.5

🔹 模型相关
  #模型列表 — 查看所有模型
  #模型 <序号> — 切换模型
  #当前 — 查看当前模型

🔹 人格相关
  #人格列表 — 查看所有人格
  #人格 <序号> — 切换人格
  #当前人格 — 查看当前人格
```

### 切换模型

```
#模型列表
```

```
📋 模型列表

1. 🔴<gpt-4o>
2. 🔵<claude-3.5-sonnet> ⬅️
3. 🔴<deepseek-chat>

🟢切换模型请输入指令：
#模型 <序号>
```

```
#模型 1
```

```
✅ 已切换到：gpt-4o
```

### 切换人格

```
#人格列表
```

```
🎭 人格列表

1. 🔴<default>
2. 🔵<优香> ⬅️
3. 🔴<爱丽丝>

🟢切换人格请输入指令：
#人格 <序号>
```

```
#人格 3
```

```
✅ 已切换到：爱丽丝
```

## ⚠️ 注意事项

- **仅管理员可用**：所有指令均需管理员身份才能执行
- **会话级生效**：模型和人格的切换仅对当前会话生效，不影响其他会话
- **人格优先级**：通过 `#人格` 切换的人格优先级高于全局默认人格设置
- **序号从 1 开始**：输入序号时请从 1 开始，不是从 0 开始
